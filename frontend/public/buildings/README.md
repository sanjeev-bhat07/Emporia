# Building Images

Place your reference building images here to use them in the game.

## Required Images

Save your uploaded reference images with these names:

- `building1.png` - First cyberpunk building from your references
- `building2.png` - Second building
- `building3.png` - Third building  
- `building4.png` - Fourth building
- `building5.png` - Fifth building
- `central-exchange.png` - The main stock exchange building (should be the most prominent)

## Image Guidelines

- Use the actual images you provided as references
- PNG format with transparency works best
- Buildings should be cropped to show just the structure
- Consistent scale helps maintain visual coherence
- No background - just the building silhouette

The app will automatically load these images and use them as the actual buildings in the city.

If images aren't found, the app will show simple colored placeholders using the company's brand color.
